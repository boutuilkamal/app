# AI Health Coaching Platform - Mobile App

React Native mobile application built with Expo.

## Getting Started

### Prerequisites
- Node.js 18+
- Expo CLI
- iOS Simulator (Mac) or Android Studio

### Installation

```bash
cd mobile
npm install
```

### Running the App

```bash
# Start Expo development server
npm start

# Run on iOS
npm run ios

# Run on Android
npm run android

# Run on web
npm run web
```

## Building for Production

### iOS

```bash
eas build --platform ios
```

### Android

```bash
eas build --platform android
```

## Publishing

```bash
eas submit --platform ios
eas submit --platform android
```

## Features

- Native iOS and Android support
- DNA and blood report upload
- Real-time AI coaching
- Personalized programs
- Progress tracking
- Offline support

## Tech Stack

- React Native
- Expo
- TypeScript
- React Navigation
- React Query
- Zustand (State Management)
